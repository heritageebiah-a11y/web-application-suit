# Uni Market - Web Application

A marketplace for university students to buy and sell items.

## Features
- User Register & Login
- Add Item with Title, Description, Price, Category, Seller Name, Phone, Image
- View All Items
- Search Items
- Delete Item
- Chat Seller Directly on WhatsApp
## Tech Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: SQLite

## How to Run
1. Backend:
   cd backend
   npm install
   node server.js

2. Frontend:
   Open frontend/index.html in browser
